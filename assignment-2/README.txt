THE BROWN VANITY — ASSIGNMENT 2 Static, Responsive E-commerce Website

STUDENT Mahum Riaz

COURSE Web Technologies (CSC336)

PROJECT DESCRIPTION The Brown Vanity is a static e-commerce storefront
for a curated beauty and accessories boutique. The project includes: -
index.html: homepage / product listing page with eight product cards -
product.html: individual product detail page - style.css: styling,
layout and responsive rules - images/: product photographs used by the
pages

REFERENCE WEBSITE Name: Cozmetica.pk Reference page: Makeup collection
URL: https://cozmetica.pk/collections/makeup

The reference was used for the general structure of a cosmetics product
listing page. The Brown Vanity has its own brand identity, content,
product photography, colours and styling.

TECHNOLOGIES - HTML5 - CSS3 - Bootstrap for framework-based
layout/navigation support - Flexbox and CSS Grid for page layout - CSS
media queries for responsive styling

ASSIGNMENT SCOPE This is a static front-end prototype. The cart and
shopping controls are visual only and are not connected to a backend.
JavaScript functionality is not included.
